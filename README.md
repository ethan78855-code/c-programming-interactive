# C 語言互動講義

把「程式設計（C 語言）」課程的 8 份講義整理成可以動手玩的互動圖解網站。

| 講次 | 主題 |
| --- | --- |
| 01 | 電腦與 C 程式入門：編譯與連結、Hello CCU、函式、跳脫序列 |
| 02 | 資料型態、運算子與輸入輸出：型態大小、作用範圍、printf / scanf |
| 02+ | 進位系統：2、8、10、16 進位 |
| 03 | 運算子與流程控制：邏輯／位元運算、陣列與字串、if / switch |
| 04 | 迴圈與二維陣列：for / while、巢狀迴圈、矩陣乘法、printf 格式化 |
| 05 | 字元、字串、檔案與亂數：ctype / string.h、fgets、fopen、rand |
| 06 | 呼叫堆疊、遞迴與儲存類別：階乘、費氏數列、河內塔、static / extern / const |
| 07 | 編譯、記憶體與參數傳遞：CPU 執行循環、記憶體配置、傳值／傳址 |

純靜態網站（HTML + CSS + 原生 JavaScript），不需要建置步驟。本機預覽：

```
python -m http.server 8000
```

然後開啟 <http://localhost:8000>。

內容整理自王志航老師「程式設計（C 語言）」課程講義，範例程式碼取自課程提供的 GitHub Gist。
